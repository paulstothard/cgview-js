Inline feature labels with external fallback

Proposed Annotation extension for readable labels without duplicating labels that already fit inside features.

Fit before fallback

Names are placed inside only when the rendered feature has enough length and height. Unplaced names remain eligible for the existing external annotation layout.

Layout-aware text

Circular labels follow the feature arc glyph by glyph; linear labels remain straight and centered.

Bounded adaptation

Shrinking stops at a configured readable floor. Truncation is a separate opt-in policy and is disabled here.

Deterministic placement

Feature length and favorite status establish stable collision priority instead of depending on draw order.

Readable contrast

When no explicit inline color is supplied, black or white is selected against the composited feature color.

Backward compatibility

annotation.labelPosition defaults to external, preserving existing maps and JSON.
