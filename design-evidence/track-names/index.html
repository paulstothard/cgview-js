Feature-track names at close zoom

Proposed compact identifiers for retaining lane context after overview structure leaves the viewport.

Actual track identity

Text comes from track.name, not from a legend item, feature type, or data method.

Only when useful

Names appear after lanes become individually readable and only when their rendered side has sufficient thickness and length.

Track-aware grouping

An around track gets one identifier per visible side; multiple lanes on the same side share one identifier.

Stable edge placement

Labels stay just inside the leading visible edge so the viewer can identify lanes without covering their center.

Layout parity

Circular text follows the track arc; linear text remains straight. Both receive an automatic background-derived halo.

Backward compatibility

The upstream proposal recommends opt-in behavior initially, even though the development demo enables it.
