Detailed sequence ruler

Proposed layout-aware coordinate labels that remain legible around circular maps and in exported graphics.

True circular text

Each glyph follows the exact ruler circumference. Labels on the lower semicircle reverse direction so they stay naturally readable.

Linear parity

The same setting falls back to ordinary straight coordinate text when the map is linear.

Automatic protection

A rounded background-colored text stroke is painted before the glyph fill. It protects the letters without drawing rectangular boxes.

Foreground ordering

Labels are painted after slots and sequence detail so the protection cannot be overdrawn by map data.

Export parity

The glyph geometry and halo use the same Canvas calls for live rendering and SVG export.

Backward compatibility

ruler.labelStyle remains default unless a map selects the detailed style.
